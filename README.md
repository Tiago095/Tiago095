## 🧭 O que faço

Trabalho na fronteira entre sistemas e produto: gosto de perceber como as coisas funcionam por dentro (C/C++, sistemas distribuídos, bases de dados) e depois construir algo que as pessoas realmente usam (web, ferramentas, automação).

Atualmente disponível para novas oportunidades — e a manter projetos pessoais vivos entretanto.
