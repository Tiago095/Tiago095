I work at the intersection of systems and product: I like understanding how things work under the hood (C/C++, distributed systems, databases) and then building something people actually use (web, tools, automation).

Currently open to new opportunities, while keeping personal projects alive in the meantime.

### [Life RPG](https://github.com/Tiago095/Life_Rpg)
